Security note

GitHub Pages is a static public website. Do not put passwords or secret API keys directly into the repository.

For this first version, the optional Apps Script access key is stored in the manager's browser and checked by the spreadsheet backend. For stronger multi-user security, add Google sign-in or a proper authenticated backend later.
